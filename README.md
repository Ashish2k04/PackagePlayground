# PackagePlayground

A personal collection of JavaScript packages I have learned.

Each folder contains a separate package with:

- 📦 Working code examples
- 💬 Code comments explaining what each part does
- 📖 A README explaining how the package works
- ⚙️ Installation and setup instructions
- 🔑 Environment/API key setup where required

The goal is simple: instead of searching through old projects or documentation, I can quickly revisit a package and understand how to use it again.
